# 校时只在电教猫内部生效，全屏时钟不跟时间偏移

教室电脑的系统时钟常常不准，学校铃声又常常和标准时间差几秒。「设置 › 时间」因此分两层：Time Sync 向时间服务器（默认阿里云）测出系统时钟快或慢多少，得到 Calibrated Time；Time Offset（可带 Daily Drift）再加在它上面，得到 Bell Time，Scheduled Task 按 Bell Time 匹配。有两处做法和直觉不同：

1. 校时不改 Windows 系统时钟。电教猫只记住偏差，自己用 Calibrated Time，右下角的时钟和其他软件都不受影响；运行中 Windows 时钟被人改了或被系统自己对了时，电教猫的时间不跟着跳，并立刻重新同步。
2. Fullscreen Clock 显示 Calibrated Time，从不加 Time Offset。全屏时钟给学生看的是标准时间，偏移只为让到点的动作和铃声对齐；所以开了偏移以后，全屏时钟和到点的播报会差几秒，这是有意的。

## Considered Options

**直接把 Windows 系统时间改对**：要管理员权限，讲台上会弹 UAC；改的是整台电脑，别的软件和学校自己的对铃安排都会被牵动。

**全屏时钟也放进"不偏移"清单，默认勾上**：留出让钟跟铃对上的选择，但老师明确要全屏时钟只跟校准时间走，不提供这个开关。

**把上次测出的偏差存下来，离线开机时接着用**：主板电池没电的机器每次开机时钟都被重置，存下来的偏差每次都是错的。每次启动在第一次同步成功之前用系统时间。

## Consequences

- 所有读"现在几点"来决定行为的地方都要经同一处取时间：调度循环、全屏时钟和它的 Setting Preview、新建任务对话框的默认时间。日志、报错上报、缓存和日志的过期清理看文件时间，托盘预览里的任务栏时钟模仿 Windows，它们仍用系统时间。
- 考试倒计时、进程守护和关机提示的倒数只量经过了多久，校时和偏移都不影响它们。
- 只走 NTP（UDP 123）。学校防火墙挡住时同步失败并显示原因，不改问电教猫服务端。
- 已有用户升级后 Time Sync 默认打开：原本靠把 Windows 时钟调快或调慢来对铃的学校，任务时刻会变，需要改用 Time Offset。更新日志写明这一点，软件里不另弹提示。
