# 间隔任务按起点排、错过只补一次；换壁纸是一种任务类型

老师要两样东西：自动任务能"每隔一段时间"执行，电脑没开的那几次下次开机补上；执行时能换 Windows 桌面壁纸，固定一张或者按列表轮换。两样都放进自动任务：「触发时机」多一项「间隔时间」（Interval Task），「任务类型」多一项「更换壁纸」（Wallpaper Task）。有几处做法和直觉不同：

1. 到点时刻是"起点 + k × 间隔"，与上次实际何时执行无关。「每 1 天」默认从今天 00:00 起排，意思就是"每天第一次开机时换一张"。从上次执行起算的话，周一 08:05 开机补执行了一次，周二 07:55 开机就要等到 08:05（已经上课了）才换，而且越漂越偏。
2. 错过多少个到点都只补一次（Catch-up Run）。只补这条规则存在、开着、起点和间隔没改过期间的到点：新建、修改起点或间隔、打开开关都从那一刻重新算，与 Task Master Switch"重新开启后不补"一致；上一次还没跑完时到的点算已执行。「固定时间」的自动任务仍然只补最近 60 秒，补执行只属于间隔任务。
3. 换壁纸做成任务类型而不是 Home Action。轮换列表要排序、按文件夹导入、标出 Current Wallpaper，编辑器塞不进动作序列的一行；轮换进度是状态，而 Home Action 全都没有状态。主页卡片另有一种 Home Action「设置壁纸」，只设一张固定的图、不轮换；它和其他 Home Action 一样，Custom Home Card 和「自定义」任务都能用，所以自动任务里设固定壁纸有两条路，这是有意的。
4. 列表只记图片的路径，不复制图片，与软件图标、托盘图标的自定义图片一样。找不到的图跳过但留在列表里，U 盘插回来就又能用。

## Considered Options

**从上次执行起算**：实现最简单，但时刻漂移，"每天"没法落在固定的时刻。

**错过几次补几次**：每小时一次的任务周末没开机，周一开机连跑 48 次。

**换壁纸做成 Home Action**：主页也能轮换，但要给无状态的动作序列加上状态和一个塞不进一行的编辑器。

**添加时把图片复制进 App Data Directory**：原图删了照样能换，也随 Storage Migration 走；但用文件夹导入几百张 4K 照片就是 1 GB 上下。

## Consequences

- 补执行要知道上次停在哪：每条任务的起算时刻、最近执行的到点和 Current Wallpaper 存在 `cfg.homeCardTaskState`，按任务 ID 记，与 `cfg.homeCardTasks` 分开。合在一起的话，每执行一次都改写任务列表，自动任务页会整页重建、展开着的卡片收起来。
- 起算时刻由调度循环在同一轮里先核对、后判断：起点、间隔、启用开关或总开关一变就从这一刻起算，所以改完规则不会立刻补执行改之前的到点。
- 时间往回调后，执行过的到点不再执行；但记下的时刻比现在晚一天以上时（主板电池没电、时钟被重置后又校正）当作时钟出了错，从现在重新起算，否则任务要停到那一天才再跑。
- 只换当前用户的桌面壁纸，所有屏幕同一张，契合度沿用 Windows 当前设置，锁屏不动。被组策略锁定壁纸的电脑上 Windows 照样回答成功，电教猫看不出来。
